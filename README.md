Week 3 Assignment: Grade Reporter & Bug Hunt

Project Description

This project demonstrates my understanding of Python loops, conditional statements, calculations, and debugging.

Files Included

1. grade_reporter.py

Uses a for loop and if/elif/else statements to calculate learner grades, count passes and failures, and calculate the class average.

2. bug_hunt.py

Demonstrates debugging a while loop by correcting three bugs to calculate the sum of numbers from 1 to 5.

Bug Hunt Reflection

The hardest bug to find was the logical error in the while loop condition. The program could run without displaying an error, but it produced an incorrect answer because it stopped before adding 5.

I knew something was wrong because the expected answer was 15, but the program produced 10. I fixed this by changing the condition from "count < 5" to "count <= 5".
